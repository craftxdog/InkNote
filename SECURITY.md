# Security policy

## Supported versions

Security fixes are provided for the current `0.1.x` release line.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
[private vulnerability report](https://github.com/craftxdog/InkNote/security/advisories/new)
from the repository's Security tab. If private reporting is unavailable, contact
[@craftxdog](https://github.com/craftxdog) privately.

Include a clear description, reproducible steps, affected version, and the
potential impact. We will investigate the report and coordinate remediation
before public disclosure.
