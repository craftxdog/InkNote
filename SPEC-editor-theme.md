# Spec: Editor syntax theme refinement

## Objective

Make Markdown and common code fences visually legible in both built-in themes through semantic CSS tokens, without copying Inkdrop's proprietary theme files or adding a theme framework.

## Success criteria

- Headings, Markdown punctuation, links, code strings, keywords, comments and literals have distinct contrast-safe colors.
- Preview and editor use the same light/dark semantic palette.
- Existing Vim and global shortcut behavior remains unchanged.
